# 传感工况实验数据与复现说明

四项实验共用一条仿真轨道和姿态真值。第一组种子覆盖十二个工况，第 2–5 组各覆盖八个工况，共有 44 条滤波记录。包内提供全部观测、结果、配对指标及四张图。以下 MATLAB 命令从发布包根目录执行。

## 直接读取结果和重新出图

用表格软件打开 [分段指标](results/metrics.csv)、[各组配对差值](results/paired_by_seed.csv) 和 [配对汇总](results/paired_summary.csv) 即可查阅结果。用 MATLAB 读取观测或重绘图形只需本包。下列示例读取一组定位结果并用已有制图数据绘制图三。

```matlab
addpath('code')
S = load(fullfile('data','rep01_ar10.mat'),'obs','out');
T = load(fullfile('data','truth.mat'),'t');
plot(T.t, S.out.pos), xlabel('时间（s）'), ylabel('三维位置误差（m）')
summarize_sensor_results(3)
```

图号 1–4 依次对应观测缺测、星敏图像噪声、伪距时间相关性和星敏观测延迟。绘图函数读取随包的 `results/figure_inputs.mat`，把同名 PNG 写入 `results`。如需从 44 份滤波记录重新计算指标并更新制图数据，先执行 `summarize_sensor_results([])`。使用 Windows PowerShell 时可依次启动单线程 MATLAB 进程生成四图。

```powershell
$entry = (Get-Command matlab).Source
Push-Location -LiteralPath 'code'
try {
    foreach ($figureId in 1..4) {
        & $entry -wait -singleCompThread -batch "summarize_sensor_results($figureId)"
        if ($LASTEXITCODE -ne 0) { throw "第 $figureId 张图生成失败" }
    }
} finally { Pop-Location }
```

## 从头运行仿真

本次实验使用 MATLAB R2025b。公开包中的 `code` 目录包含工况生成、回放、统计和绘图程序。从头生成观测时，将课程共享的 MATLAB 工程 `satellite_nav_sim` 放在与本包同级的位置。生成程序调用该工程的 `config`、`truth`、`utils`、`sensors`、`fusion`，读取其中的北斗广播星历 `data/gnss/BRDC00WRD_S_20261740000_01D_MN.rnx`，以及 `results/data` 中的 `hipparcos_catalog_mag65.mat` 和 `hipparcos_pair_catalog_mag65.mat`。程序沿用这些输入生成星图、伪距和陀螺量测。带真值、噪声及星号的数值文件是本次仿真的输出。

```matlab
addpath('code')
run_sensor_experiments(1:5)  % 更新五组实验在 data 目录下的文件
summarize_sensor_results([]) % 从全部工况重新生成指标及绘图数据
```

将 `1:5` 改为一个组号可单独复算该组。若要复算补充的八维北斗归一化创新平方（NIS），在上述共享工程可用时执行 `compare_bds_nis`。程序读取发布包内五组已保存的观测，在北斗更新前计算创新，使用八自由度卡方分布的 99% 分位数 20.090235 统计超限次数。结果分别写入 [逐次更新](results/北斗NIS逐次更新.csv) 和 [分组汇总](results/北斗NIS对照汇总.csv)。

## 工况与种子

| 文件中的工况名 | 含义 | 变化的观测时刻 |
|---|---|---|
| `baseline` | 正常基线，像素噪声 0.10 像素，伪距白噪声 3 m，额外延迟为 0 | 全程正常 |
| `star_sparse`、`gnss_sparse` | 分别移除星敏、北斗 10 次观测 | 301、303、…、319 s |
| `star_burst`、`gnss_burst` | 分别连续移除星敏、北斗 10 次观测 | 306–315 s |
| `pixel005`、`pixel020`、`pixel040` | 星点中心每轴噪声标准差分别为 0.05、0.20、0.40 像素 | 300–359 s |
| `ar10` | 伪距噪声的相关时间为 10 s，理论标准差为 3 m | 300–359 s |
| `delay005`、`delay010`、`delay020` | 星敏量测分别延迟 0.05、0.10、0.20 s 到达 | 采样时间 300–359 s |

文件名前缀 `rep01` 至 `rep05` 表示配对组号。同组内初始状态、陀螺、轨道、姿态和相应观测的随机抽样一致。以第一组为例，初始化、陀螺、北斗种子分别为 10、1、40，星敏第 j 次采样的种子为 1000+j（j 从 1 开始）。每增加一组，这四类种子的编号均增加 10000。不可见卫星的噪声和相关过程初值采用独立随机流，种子为 730000+组号。

## 给算法组的数据

`data` 下均为 MATLAB v7 文件。每个工况由以下三份文件组成。全体工况共用一份真值，同组工况共用陀螺和基线原始观测。

| 文件 | 内容 |
|---|---|
| `truth.mat` | 时间 `t`（s，100 Hz），惯性系位置 `r_true`（m）、速度 `v_true`（m/s）、姿态 `q_true`（每行一个标量在前的四元数）和本体系角速度 `omega_true`（rad/s）。用于生成观测与计算误差。 |
| `repXX_base.mat` | `base` 中的陀螺 `gyro`（3×60001，rad/s）、其协方差 `gyroR`、北斗协方差 `gnssR`、基线星点像素 `starImage`、原始北斗观测 `rawGnss`。另存原滤波器初态 `X0`、协方差 `P0`、配置 `cfg` 和完整噪声序列 `noise`。 |
| `repXX_工况名.mat` | `obs` 为该工况的观测，`out` 为参考 ESKF 结果。低频观测均按采样时刻 `obs.epochs` 排列（0–600 s，共 601 次），星敏实际到达时刻见 `obs.arrival`。基线工况文件名为 `repXX_baseline.mat`。 |

- **按已解算的传感器量测进行融合**。读取 `obs.starQ`（4×601）和随帧协方差 `obs.starR`，仅在 `obs.starValid` 为真时按到达时刻更新。北斗使用 `obs.gnssZ`（8×601）与 `obs.gnssValid`，各列依次为惯性系三维位置、三维速度、接收机钟差（m）和钟漂（m/s）。沿用原工程的更新次序：陀螺更新、预测至下一步、北斗更新、星敏更新。t=0 用于初始化，首次低频更新在 1 s。
- **从更早的测量环节开始解算**。星点数据通常在 `base.starImage`，像素噪声工况取 `obs.starImage`。每帧各行为星号、观测横纵像素、理想横纵像素；理想像素和星号对应关系供评价。北斗用 `base.rawGnss`，相关噪声工况取 `obs.rawGnss`。各行按采样时刻和北斗卫星号标识，包含原始及钟差校正后的伪距、伪距率、卫星地固系位置和速度。缺测或延迟工况在输入估计器前仍须按该工况的有效标志和到达时刻执行。
- **核对结果**。在 100 Hz 时间轴上，`out.pos`、`out.vel`、`out.att` 为三维位置误差长度（m）、三维速度误差长度（m/s）和最小姿态角误差（角秒）。`out.dpos` 为惯性系带符号的位置误差，等于估计减真值。原始传感器的精度指标按有效低频观测计算。原始观测中随附的真值、注入的噪声和参考 ESKF 结果仅供生成或评价。

例如，以下代码可取得第一组中实际到达滤波器的延迟星敏量测：

```matlab
S = load(fullfile('data','rep01_delay010.mat'),'obs');
use = S.obs.starValid(:) & S.obs.epochs(:)>0;
sampleTime = S.obs.epochs(use);
arrivalTime = S.obs.arrival(use);
qMeasured = S.obs.starQ(:,use);
R = S.obs.starR(:,:,use);
```
