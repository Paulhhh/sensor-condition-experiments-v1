# 传感工况实验部分V1

本项目研究固定卫星运动与 20 维误差状态扩展卡尔曼滤波器（ESKF）时，传感器观测质量对姿态与定位精度的影响。四项实验共用一条 600 s 仿真轨迹。首组随机种子覆盖 12 个工况，其中 8 个工况使用五组配对种子复验，合计 44 次滤波运行。

| 实验 | 测量结果 |
|---|---|
| 星敏、北斗缺测 | 同样移除 10 次有效观测，连续与分散缺测的误差峰值排序受传感器、种子和统计窗口影响。 |
| 星敏图像噪声 | 首组中，星点测量噪声由 0.10 增至 0.40 像素，事件段融合姿态均方根误差由 9.00 增至 21.24 角秒。第 2 组在 317 s 出现一次星图误匹配，融合姿态误差峰值达到 12.72°。 |
| 北斗伪距噪声相关性 | 在相同的 3 m 理论标准差下，首组北斗单独定位 X、Y、Z 误差最长连续同号时间由 7、7、4 s 增至 27、25、21 s。 |
| 星敏量测延迟 | 延迟 0.10 s 时，五组的事件段融合姿态均方根误差均升高，平均增量为 28.22 角秒。 |

`data/` 保存仿真真值、观测和滤波结果，`results/` 保存图表与统计量，`code/` 保存实验程序。使用 MATLAB 可直接读取随包数据、重新统计和绘图。从头运行导航仿真还需课程组共享的 `satellite_nav_sim` 基础工程。
